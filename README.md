## Overview

Play For Good is a social sports application with a charity-oriented product concept, combining user profiles, organizations, donation flows, game mechanics, and admin-facing management screens.

## Platforms

- iOS
- Android
- Web / admin surfaces are present in the export

## Store Links

- App Store: https://apps.apple.com/ru/app/play-for-good/id6749274248
- Google Play: https://play.google.com/store/apps/details?id=com.xmethod.playforgoodapp

## Tech Stack

- Flutter
- Dart
- FlutterFlow
- Supabase Auth
- Supabase Database
- Supabase Storage
- Flutter Web

## Notable Capabilities

- organization and community-oriented user flows
- admin panels and data tables in the same codebase
- donation / payment-related custom actions
- deep linking support via `app_links`
- custom widgets for dashboards, scores, and donation interactions

## Repository Notes

- repository prepared for portfolio publishing from the latest available export
- backend in this export is centered around Supabase rather than Firestore
