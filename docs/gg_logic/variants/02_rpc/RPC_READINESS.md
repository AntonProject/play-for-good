## Проверки перед live-применением и после ручного UI

* Подтвердить продуктовый timezone и интерпретацию существующих timestamp без
  зоны. Локальный SQL сравнивает исторические даты напрямую с UTC-календарём.
* Проверить, что profile INSERT/UPDATE разрешены текущими RLS для новых полей.
  Live Auth создаёт профиль до OTP: одного AFTER INSERT для бонуса недостаточно.
* Создание сразу подтверждённого тестового пользователя админом требует среды
  **до** автоматической выдачи; иначе signup_test=false создаст prod-бонус.
  Этот Edge путь нельзя считать готовым без проверки перед внедрением.
* Старые клиенты не фильтруют новые test-строки. Default false не решает их
  SELECT; граница доступа для старых сборок описана в START, не внедрена пакетом.
* Проверить свою новую игру, возврат в профиль, чужую игру и изменение места,
  listener reconnect/resume, ошибку RPC, отмену фильтра, пагинацию и несколько
  бейджей разных лет. Не выдавать локальные mock/SQL тесты за проход на устройстве.
* Награды фиксированных сезонов не меняются после удаления игры; All-Time
  пересчитывается. Cron вызывает finalize с Broadcast; реальная доставка в
  открытые страницы проверяется только после настройки Supabase/FF.
