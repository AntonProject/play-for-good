# Поле test: места ручного изменения FF

Общее дополнение для всех вариантов. Здесь меняется только среда данных;
перенос расчётов на RPC других экранов не входит в вариант 02.

| Место в экспортированном проекте | Что поменять в FF |
|---|---|
| PlayPaymentPage, GamesTable.insert | Записать test из Environment; сохранить status/payment flow |
| Создание приглашения / InviteUser | Записать invites.test из Environment; начисления приглашения наследуют эту среду |
| SignInAfterOtpVerification, signup INSERT/UPDATE users | Записать signup_test в обеих ветках первоначальной регистрации; после OTP/готового профиля обязательно claim bonus; при обычном login среду не менять |
| GoodGamesPage | Базовый: test у запросов игр. RPC: p_test у всех трёх actions |
| UserProfilePage / профильный диалог | test у игровых запросов организаций/расчётов; p_test у RPC статистики |
| HomePage | test у глобального списка completed games |
| EnergyPage, Energy / EnergyGuest компоненты | test у списков/stream и сумм |
| OrganisationPage | test у истории игр и счётчиков |
| SponsorList / ProfileGamesOrg диалог | test у запросов игр |
| FinishPage | По ID текущей игры; если добавляется среда, передавать ту же, что при создании |
| gamesCount | test у count-запроса, иначе будут считаться обе среды |
| Админские статистика / списки | Явный выбор prod/test или оба; не скрывать среду |

В FlutterFlow у Backend Query добавить AND `test Equal To Environment.test`.
У старого `.stream()` Dart API не следует слепо добавлять второй `.eq`:
используемая версия stream builder ограничивает сочетание фильтров. В FF
проверить сгенерированное выражение/компиляцию; при необходимости stream
фильтрует среду, completed отбирается из результата, либо обычный Query+
refresh/listener. Не оставлять тестовые данные в глобальной сумме.

Флаг `test` платежного Edge Function (`test_mode`) уже есть в приложении,
но он не помечает автоматически строку games. Сохранение этого поля в INSERT
не меняет финансовую функцию. При старте проверить реальный Edge Function,
чтобы последующие UPDATE не меняли среду; локального исходника его здесь нет.

Это карта привязок, не заявление что все сгенерированные страницы уже
изменены. Каждая конкретная cloud-правка делается вручную после выбора пакета.
