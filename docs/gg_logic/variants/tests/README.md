# Проверки локальных комплектов

Фикстуры синтетические: UUID/почта/игры не взяты из настоящего проекта.
`parity_fixture.json` содержит одинаковые данные для Dart и SQL, до/после
фиксации сезона и изменения исходных игр/имени игрока.

## SQL

Нужна новая одноразовая PostgreSQL DB с сокетом в `/private/tmp/` и ролью
владельца. Не передавать строку подключения настоящего Supabase.

```sh
python3 docs/gg_logic/variants/tests/check_variants.py \
  --psql /path/to/psql --socket /private/tmp/gg-test \
  --port 55440 --user local_owner --database fresh_fixture_db \
  --export /private/tmp/gg-parity-fixture.json
```

Проверяет базовый бэк, затем RPC, затем админку: SQL и права, среду, регистрацию,
бонус/даты, метрики, границы сезона, сохранение/повторную фиксацию, администратора,
предпросмотр, запрет пересечений, будущий сезон, сохранность правок админа,
удаление аккаунта без потери сохранённых результатов. Cron scheduler не эмулируется:
проверяются вызываемые им функции. Не нагрузочный тест настоящей БД.

## Dart / Flutter

Подготовить отдельный маленький harness с версиями SDK, использованными в
проверке. Он копирует только новые Custom Code и реальные GamesRow/UsersRow,
не меняет исходный FlutterFlow export:

```sh
python3 docs/gg_logic/variants/tests/prepare_flutter_check.py --output /private/tmp/pfg-gg-v2-check
```

В полученном каталоге: `flutter pub get`, `dart analyze lib/custom_code`, затем
`flutter test` с `GG_VARIANTS_FIXTURE`, путь напечатает скрипт. Можно использовать
сохранённый parity_fixture.json или свежий export из SQL проверки.

Результат 1 октября 2026: SQL проверки прошли; 3 Dart-проверки совпадения и 2
проверки scroll physics прошли. Dart analyze новых файлов — без ошибок/предупреждений,
3 информационных сообщения deprecated DropdownButtonFormField.value.
Полная сборка экспортированного приложения и компиляция в облаке FF не выполнялись.

Дополнительная проверка CLI-комплектов: регистрация basic/rpc/admin повторяется
без изменения результата и не затрагивает страницы. Локальный валидатор FF:
у исходного проекта 286 замечаний, у каждого кандидата те же 286, новых нет.
RPC-комплект также прошёл pipeline dry-run без cloud push. После исправления
`ggV2ProfileStats` отдельно проверена передача `p_test=false/true` через mock HTTP:
оба теста прошли. Backend-данные и облачные страницы этими проверками не менялись.
